# ТЗ: EnglishFlow PWA — приложение для изучения английского языка

## Контекст проекта

Персональное PWA-приложение для изучения английского с нуля (уровень A0 → A2).  
Пользователь: один человек, занимается 15–30 минут в день.  
Цель: повседневное общение, туристические ситуации, без делового/технического английского.

---

## Технические требования

- **Стек:** чистый HTML + CSS + JavaScript, без фреймворков (React, Vue и т.д.)
- **Структура:** один файл `index.html` + отдельные файлы данных (JSON)
- **PWA:** обязательно Web App Manifest + Service Worker (офлайн-режим)
- **Голос (вход):** Web Speech API — SpeechRecognition
- **Голос (выход):** Web Speech API — SpeechSynthesis (TTS, бесплатно)
- **AI фидбек и диалоги:** OpenAI API через Responses API
  - фидбек по произношению: `gpt-5-mini` как основной вариант для лучшего качества коротких объяснений
  - диалоги и tutor-mode: `gpt-5-mini` для регулярного использования, `gpt-5` как опциональный режим повышенного качества
  - распознавание речи через OpenAI, если браузерный Web Speech API не подходит: `gpt-4o-mini-transcribe`
  - озвучка через OpenAI, если браузерный SpeechSynthesis не подходит: `gpt-4o-mini-tts`
- **Данные:** localStorage (прогресс пользователя, стрик, изученные слова)
- **Аккаунты:** на старте регистрация не нужна. Каждый пользователь хранит прогресс локально на своём устройстве. Будущая синхронизация через аккаунт должна добавляться отдельной фазой и не ломать локальный прогресс.
- **Хостинг:** GitHub Pages / статический хостинг для PWA + serverless-прокси для OpenAI API
- **Безопасность API:** OpenAI API key нельзя хранить в `config.js` или другом публичном файле PWA. Ключ хранится только на серверной стороне: Cloudflare Worker, Netlify Function, Vercel Function или VPS.
- **Совместимость:** iPhone 13 Mini (Safari), Samsung Android (Chrome), MacBook M2 (Safari/Chrome), Windows 10 (Chrome/Edge)

> ⚠️ Важно: Web Speech SpeechRecognition на iOS Safari работает частично. Предусмотреть fallback — ввод текстом вместо голоса.

## Модули приложения

### 1. Карточки слов (приоритет #1)
- Карточка: слово (EN) + транскрипция + перевод (RU) + картинка-ассоциация
- Озвучка слова через SpeechSynthesis (голос `en-US`)
- Настройка голоса: пользователь может выбрать авто-режим, предпочтение мужского/женского голоса и конкретный доступный английский голос устройства
- Алгоритм интервального повторения (SRS) — показывать слова которые пользователь плохо знает чаще
- База: 500+ базовых слов, разбитых по темам
- Режимы: показать слово → вспомнить перевод → оценить себя (знал / не знал)

### 2. Мини-игры и квизы (приоритет #1)
- **Угадай перевод** — 1 слово + 4 варианта ответа, выбрать правильный
- Темы первой игры: базовые слова, путешествия, автомобили, Minecraft-лексика для детской мотивации
- **Собери предложение** — слова перемешаны, нужно поставить в правильный порядок
- **Тап-пары** — нажать картинку/ассоциацию, затем подходящее английское слово; верная пара подсвечивается зелёным
- **Заполни пропуск** — предложение с пропуском, выбрать нужное слово
- **Сопоставь пары** — 6 слов EN + 6 переводов RU, соединить правильно
- Таймер + очки за каждую игру

### 3. Произношение (приоритет #2)
- Кнопка "Записать голос" → SpeechRecognition слушает пользователя
- Распознанный текст сравнивается с эталонным словом/фразой
- Отправка в OpenAI API через защищённый serverless-прокси: `"Пользователь должен был сказать: '{слово}'. Он сказал: '{распознанный текст}'. Дай короткий фидбек на русском — правильно ли произношение и что улучшить."`
- Основная модель: `gpt-5-mini`, потому что качество фидбека важнее минимальной экономии
- Ответ OpenAI показывается под карточкой
- На iOS: если SpeechRecognition недоступен — показать текстовое поле для ввода вручную

### 4. Диалоги и ситуации (приоритет #3)
Интерактивные сценарии, OpenAI API играет роль собеседника:
- В аэропорту (регистрация, паспортный контроль, поиск выхода)
- В отеле (заселение, вопросы персоналу)
- В кафе / ресторане (заказ, счёт)
- В магазине (цена, размер, оплата)
- Знакомство (имя, откуда, чем занимаешься)
- Транспорт / такси (куда ехать, сколько стоит)

Системный промпт для диалогов:
```
Ты — англоязычный собеседник в сцене "{название сцены}". 
Пользователь учит английский с нуля (уровень A0-A2). 
Отвечай короткими простыми фразами. 
После каждого своего ответа добавляй перевод на русский в скобках.
Если пользователь ошибся — мягко поправь и покажи правильный вариант.
```

### 5. Геймификация
- **Стрик** — счётчик дней подряд (сохраняется в localStorage)
- **XP** — очки опыта за каждое действие: +5 за карточку, +10 за игру, +15 за диалог
- **Уровни** — каждые 100 XP новый уровень (Beginner → Elementary → Pre-Intermediate...)
- **Ежедневная цель** — выполнить минимум 10 карточек или 1 игру в день
- **Разблокировка тем** — новые темы открываются по мере прогресса

### 6. Прогресс и статистика
- Количество изученных слов
- График занятий по дням (последние 7 дней)
- Список "слабых слов" (которые пользователь часто ошибается)
- Текущий стрик и рекорд

## Контент — темы и фазы

### Фаза 1 — Выживание (старт)
Числа 1–100, цвета, дни недели, месяцы, приветствия и прощания,  
базовые вежливые фразы (yes/no/please/thank you/sorry),  
тело человека, еда и напитки, базовые глаголы (go/come/eat/drink/want/need)

### Фаза 2 — Туризм
Аэропорт и перелёт, отель, кафе и рестораны, магазины,  
транспорт и такси, деньги и цены, просьба о помощи, ориентация в городе

### Фаза 3 — Повседневное общение
Знакомство и small talk, семья и отношения, профессии и работа,  
погода, хобби и свободное время, время и даты, эмоции и самочувствие

## Дизайн-направление

Референс: https://neuform.ai/community/featured

Использовать не прямую копию, а адаптацию под учебное PWA:
- взять ощущение современного polished-интерфейса, боковое меню на desktop, сетку тем и аккуратные бейджи прогресса;
- не переносить тяжёлую тёмную AI-gallery эстетику буквально, потому что EnglishFlow должен быть удобным для ежедневных занятий 15–30 минут;
- MVP делать как светлую учебную панель с тёмными/контрастными акцентами, карточками до 8px радиуса, понятными темами и крупной центральной карточкой слова;
- позже добавить dark mode в стиле Neuform.

Рабочее название дизайна: **EnglishFlow Learning Console**.

## Архитектура деплоя

Приложение не должно зависеть от запущенного MacBook. Целевой режим:
- PWA размещается на GitHub Pages, Cloudflare Pages, Netlify, Vercel или VPS как статический сайт;
- OpenAI API вызывается только через серверный прокси;
- на телефон устанавливается PWA через браузер;
- при наличии интернета приложение работает удалённо, а базовые карточки и прогресс доступны офлайн через Service Worker и localStorage.
